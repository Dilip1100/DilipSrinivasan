# Dilip Kumar - Enterprise Portfolio

Static, GitHub Pages-ready portfolio website.

## Publish on GitHub Pages

1. Extract the ZIP.
2. Copy all extracted files to the root of the `DilipSrinivasan` repository.
3. Commit and push the files.
4. In GitHub, open **Settings → Pages** and select deployment from the repository branch and root folder.

The site uses relative asset paths and requires no build process.

## Main pages

- `index.html` - executive homepage
- `experience.html` - complete professional experience
- `Projects.html` - projects and case studies
- `Dashboards.html` - live Tableau dashboards

Legacy experience and template page names are retained as redirects so existing links continue working.
