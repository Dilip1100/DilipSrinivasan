Public source · Local prototype

ARK Airlines assistant

The problem: Answer questions about available routes and departure times using the flight records behind the application.

What I built: A Gemini-powered Gradio chat interface with Python lookup tools and a SQLite database seeded with ten sample flights.

Implementation: Route-specific and departure-city lookups use parameterized SQL. The chat carries conversation history and includes responses for missing flights and API errors.

Gradio ChatInterfaceGeminiSQLiteTool calling

Uses sample schedules. This is a local prototype, not a booking service. Running the code requires a Gemini API key and an available model.

Gateway Marketing · Hosted demos

AI-assisted business intelligence on AWS

Four industry demos combine interactive Vizro / Plotly analytics with an OpenAI adviser for automotive, steel, real estate and medical businesses.

Analytics with conversational context

The applications bring sales and revenue charts, filter-responsive KPIs, collections, a baseline forecast and revenue treemaps into one business view. The adviser receives summary figures and the user’s question to explain performance.

AWS CloudFront and EC2 host the applications, S3 supplies demonstration data, and Cognito provides sign-in.
